# Чистовик Resonance: приоритет первого тестовика

[Скачать весь комплект](resonance-clean.zip?raw=true).

Скрипты первого комплекта («который сейчас стоит») сохранены как основные. Из рабочего комплекта добавлены только 19 отсутствующих блоков. Основа оформления — присланный чистовик.

При сборке проверено сохранение всех 89 исходных блоков по одному. В версии для GitHub заменены только три значения доступа; логика этих блоков сохранена. Остальные блоки первого комплекта сохранены дословно.

## Перед установкой

Верните три значения из своих исходников локально, после скачивания. Не записывайте их в GitHub:

| Файл | Заглушка | Исходный параметр |
|---|---|---|
| `01-html-top.txt` | `__PR_PASSWORD__` | `PR.pass` |
| `01-html-top.txt` | `__NOTIFY_CLIENT_SECRET__` | `NOTIFY_HUB_CONFIG.clientSecret` |
| `02-html-bottom.txt` | `__IMAGEBAN_TOKEN__` | `FORUM.imageban_TOKEN` |

До заполнения этих значений PR-вход, уведомления и загрузка через ImageBan не будут полноценно работать.

## Установка

Сохраните резервную копию настроек форума. Полностью замените соответствующие поля, не дописывайте файлы к старому коду:

| Файл | Поле форума |
|---|---|
| `01-html-top.txt` | HTML-верх |
| `02-html-bottom.txt` | HTML-низ |
| `03-html-reply.txt` | HTML формы ответа |
| `04-css-main.txt` | Первая часть CSS чистовика |
| `05-css-extra.txt` | Вторая часть CSS чистовика |

Bubble-цитирование уже подключено один раз. Форма ответа сохранена из первого комплекта. Файлы в UTF-8, исходный импорт `style_cs.css` сохранён.

## Что сохранено и добавлено

Из первого тестовика сохранены версии и настройки эстетики, смайлов, шрифтов, предпросмотра, маски, твинков, дейликов, медиа, плейлистов, бинго, массовых лайков, обновления профиля и «Угадай миф», а также остальные его функции. Настройки маски не объединены с рабочим тестом. Твинки отправляют в тему **3**, как в первом комплекте.

Из рабочего добавлены Post Battle, банк, SNS Chat, магазин и операции с валютой/подарками, отображение баланса, дополнительные модули личной страницы/её модального открытия, карта, сайт и личные сообщения в виде чата. Их CSS-подключения перенесены.

## Проверка

14 локальных проверок пройдены. Проверены выбор версий, сохранение исходных блоков, отсутствие повторных URL внешних JS, порядок конфигураций, синтаксис 61 непустого встроенного JS-блока, обе CSS-части, настройки твинков/маски, кнопки BBCode и счётчик. Публикуемая копия дополнительно проверяется после замены трёх значений доступа.

Внешние JS и живой RusFF не проверены: доступ к forumstatic.ru, notahub.ru и тестовому форуму из облачной среды возвращает 403. Эти проверки не гарантируют совместимость всех внешних модулей на форуме.

## Параметры форума

- Автогостевая из первого: тема 7; ссылки/правила внутри `HB_CONFIG`.
- Твинки из первого: тема 3.
- Банк из рабочего: тема 6, поле валюты 2.
- Быстрые операции из первого: поле `fld2`, темы `[40,45,46,29,7,15,14,36]`, подписи администраторов для ID 6, 3, 4.
- Маска из первого: плашка `pa-fld1`, личное звание `pa-fld5`, фон `pa-fld6`. В CSS чистовика `.personal_bg`/`.personal_icon` относятся к `pa-fld4`, а `.personal_plash` — к `pa-fld5`. Фактические назначения полей нужно сверить в админке.
- Внешние магазин/баланс/личная страница могут содержать собственные привязки к полям и темам; их содержимое пока недоступно для проверки.

Сначала проверить на https://testgodstest.rusff.me/, затем переносить на https://resonance.rusff.me/. ID тем, поля и привязки сервисов нужно сверить для каждого форума. Данные сервисов и темы этот комплект не переносит.
